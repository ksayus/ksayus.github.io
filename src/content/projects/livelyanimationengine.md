## LivelyAnimationEngine

LivelyAnimationEngine 是一个专为 WPF 应用设计的动画引擎，旨在为 PCSM Next 项目提供流畅、高性能的 UI 动画效果。

### 特性

- 基于 WPF 原生动画框架的二次封装
- 支持多种缓动函数和动画曲线
- 简洁的 API 设计，便于集成
- 为 PCSM Next 项目量身定制
