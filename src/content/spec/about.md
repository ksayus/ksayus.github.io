# 关于我 / About Me

你好！我是 **Ksayus** ，一名热爱游戏技术与探索的开发者。喜欢研究游戏背后的技术原理和玩法设计，遇到感兴趣的东西总会自己动手折腾一番。

## 🛠️ 技术栈

平时主要使用以下语言进行开发：

- **Python** —— 用来写一些小工具、脚本和服务端相关的项目
- **C / C++** —— 偏底层的探索，研究性能相关的实现
- **C#** —— 主要用于 .NET / WPF 相关的桌面应用开发
- **GDScript** —— 在 Godot 引擎中折腾游戏原型

## 🎮 兴趣方向

- **游戏技术**：热衷于研究游戏引擎、渲染、动画系统等底层技术的实现原理
- **游戏玩法**：喜欢分析和探索有趣的游戏玩法机制，并尝试自己动手实现
- **折腾探索**：对未知的事物保持好奇心，喜欢从原理层面理解并亲手实践
